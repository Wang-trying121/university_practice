# C++ 逻辑电路仿真器 (C++ Logic Circuit Simulator)

## 📝 项目简介
这是一个基于 C++11 纯软件实现的数字逻辑电路仿真内核。利用面向对象（OOP）思想，将现实中的硬件逻辑门抽象为 C++ 对象，支持动态连线与信号自动传播计算。

## ✨ 核心特性
- **面向对象设计**：基于抽象基类 `Gate` 派生 `AndGate`、`OrGate`、`NotGate`、`XorGate` 等，实现高度多态。
- **动态引脚连线**：利用 C++ 指针模拟物理导线，支持将任意门的输出连接至下一级门的输入。
- **深度优先递归求值**：调用终端门的 `evaluate()` 时，信号会自动沿着指针链路反向溯源（递归），确保按正确的逻辑时序计算。
- **RAII 内存管理**：封装 `Circuit` 类集中管理组件，离开作用域自动析构释放，杜绝内存泄漏。
- **多文件工程化**：分离接口声明（.h）与具体实现（.cpp），使用严格编译选项构建。
